# 송재혁 · Network Notes

네트워크 운영·관리 직무를 지향하는 개인 기술 블로그입니다.

군 복무 중 네트워크 장비 구축·운용 경험, 5G 통신 검증 실무의 로그 분석·이슈 재현, CMD 자동화 경험을 역할 중심으로 소개합니다. IP·라우팅·스위칭과 SD-WAN 개념은 학습 노트로 구분하고, 별도로 만든 PowerShell 점검 도구를 공개 예제로 제공합니다.

## 보기

`index.html`을 브라우저에서 열면 됩니다. 외부 패키지 설치와 빌드가 필요하지 않습니다.

## 파일

- `index.html`: 블로그 홈, 검색, 분야별 글 필터, 경력 소개
- `posts/`: 개별 글 6편과 목차
- `tools/network-healthcheck.ps1`: 단일 대상의 주소 해석·ICMP·TCP 연결 점검 예제
- `.nojekyll`: GitHub Pages 정적 파일 게시 설정

## 공개 기준

회사·고객사·군 내부 자료, 실제 망 구성, 내부 IP와 로그·코드, 상세 성능 수치는 포함하지 않습니다. 실제 경험과 학습·신규 예제를 구분하며, AWS·데이터센터·SD-WAN 상용 운영 실적이나 네트워크 자격증을 추가로 주장하지 않습니다. 학습 글의 기술 설명에는 공식 문서 링크를 달았습니다.

## 점검 도구

PowerShell에서 `./tools/network-healthcheck.ps1`을 실행합니다. 기본 대상은 `127.0.0.1`입니다. TCP 연결은 `-TcpPort`를 지정했을 때만 확인합니다. 설정을 바꾸거나 장비에 로그인하지 않습니다. 결과는 실행한 환경의 관측 기록이며, 서비스 정상 동작을 단독으로 보증하지 않습니다.
